# Inchara Kart — Curated Marketplace

A modern e-commerce storefront inspired by Amazon and Flipkart, built with Next.js, TypeScript, and Tailwind CSS. Matte-black glassmorphism UI with browse, cart, reviews, and checkout.

## Features

- **Browse & search** — filter by category, sort by price/rating/reviews
- **Product detail** — specs, stock, verified customer reviews
- **Cart** — quantity controls, persistent localStorage cart, free shipping threshold
- **Checkout** — contact, shipping, and payment form (demo — no real charges)
- **Order confirmation** — order ID summary after place order

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- Unsplash product imagery
