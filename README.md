# Inchara Kart — Curated Marketplace

A modern e-commerce storefront inspired by Amazon and Flipkart, built with Next.js, TypeScript, and Tailwind CSS. Contrast glassmorphism UI with browse, cart and checkout.

## Features

- **Browse & search** — filter by category, sort by price/rating/reviews
- **Product detail** — specs, stock, verified customer reviews
- **Cart** — quantity controls, persistent localStorage cart, free shipping threshold
- **Checkout** — contact, shipping, and payment form (demo — no real charges)
- **Order confirmation** — order ID summary after place order

## Live deployment

The latest version of Inchara Kart is kindly hosted on [Vercel](https://vercel.com). You are welcome to explore the live storefront at [https://inchar-kart.vercel.app/](https://inchar-kart.vercel.app/).

No local setup is required to try the experience — browsing, cart, and checkout are available on the hosted site. Please note that this is a demonstration storefront, and no real payments are processed.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- Unsplash product imagery
